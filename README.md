# Painel Imobiliária

Painéis de Carlos Cavalcanti Imóveis (Praia Grande). Cada painel é um único `index.html` autocontido: os dados ficam embutidos no próprio arquivo, sem backend nem storage. Para abrir, dê dois cliques no arquivo ou rode `python3 -m http.server` na pasta.
